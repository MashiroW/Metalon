# assets

Put the **content** of the `Silver Blockouts` folder here (not the
folder itself), so that you get:

```
assets/chars/     David and every character's animations (glTF)
assets/levels/    every room: <level>/<room>/<room>.gltf, .png, .mask.png
assets/sprites/   mouse cursors and other sprites
assets/intro/     (videos, not used yet)
assets/sound/     music, sounds and ambiences (.ogg) -- played by the scripts
```

These resources come from the original game and are not part of this
repository.
