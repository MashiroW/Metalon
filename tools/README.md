# Tools

The game itself only needs `./assets` and `./data`. These scripts
regenerate project data -- from the **original game's CDs**, or from the
assets.

| Script | What it does |
|---|---|
| `extract_native_roll.py` | Reads every room's camera roll from the original level archives and writes `data/rooms/<level>/<room>_camera.cfg` (rooms with a non-zero roll only). |
| `silver_archives.py` | Readers used by the above: `fat*.nob` / `data*.nob` containers, RNC-1 decompression, level `.PAK` layout. |
| `find_overlay_positions.py` | Finds where each room's overlays (environmental animations, `<name>.<n>.png` in the room folders) go on the room picture, and writes `data/rooms/<level>/<room>_overlays.cfg`. Needs only `./assets`; with `--cds` it also reads each overlay's frame rate from its original `.smk`. Requires OpenCV + NumPy. |

```
python tools/extract_native_roll.py "<CD1>/SILVER" "<CD2>/Silver"
python tools/find_overlay_positions.py --cds <folder holding CD1 and CD2>
```

Requires Python 3 (standard library only), plus `opencv-python` and
`numpy` for `find_overlay_positions.py`.

### How the overlays are placed

The original game places its overlays from its compiled room scripts
(`.SCT`), whose instructions were never decoded. But an overlay is a
pre-rendered patch of the room's own picture, so its place is where its
frames match the picture: every frame (or 12 spread over it) is matched
against the room picture and its variants (`rep*.png`) by colour
difference over its opaque pixels, and the frames vote. When they don't
agree (glows, flames), a second vote compares edges instead. An overlay
fitting none of its room's pictures takes the place of the same overlay
in another room of the level. Each one is marked `sure` or `guess`; the
Scripts screen shows the guesses and lets them be moved by hand (`set`).
Checked against the positions measured earlier on the discs' `.smk`
files (DOCKSIDE, BOILAREA, TAVERN01, PONDEND...).

## Other data, generated by the game itself

- `data/rooms/<level>/<room>_intrinsics.cfg` (camera calibration against
  each room's original depth mask) is written by the exe:
  `build/silver_remaster.exe CALIBRATE_CAMERAS` (report in `build/`).
